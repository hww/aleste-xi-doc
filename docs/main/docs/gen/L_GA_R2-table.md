**Gate Array R2 — Mode, ROM Enable, LEDs**

| Field | Bits | Width | Description |
| --- | --- | --- | --- |
| **B7** | [7:7] | 1 | Must be 1 |
| **B6** | [6:6] | 1 | Must be 0 |
| **CAPS** | [5:5] | 1 | CAPS LED |
| **RUS** | [4:4] | 1 | RUS LED |
| **UPPER_ROM** | [3:3] | 1 | 1=disabled, 0=enabled |
| **LOWER_ROM** | [2:2] | 1 | 1=disabled, 0=enabled |
| **MODE** | [1:0] | 2 | 0=160x200, 1=320x200, 2=640x200 |
