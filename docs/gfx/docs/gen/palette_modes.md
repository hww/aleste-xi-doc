**Color Modes**

| Value | Name | Description |
| --- | --- | --- |
| 0 | <a id="12-bit_Native"></a>**12-bit Native** | Direct RGB, bypasses conversion |
| 1 | <a id="CPC_Legacy"></a>**CPC Legacy** | 5-bit; 16 colors + border, hardware LUT conversion |
| 2 | <a id="MSX"></a>**MSX** | 8-bit; MSX2+ compatible, perceptual mapping |
| 3 | <a id="YJK"></a>**YJK** | Advanced color space for graphic arts |
