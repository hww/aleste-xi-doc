**8255 PPI Port C — PSG Control, Cassette, Keyboard**

| Field | Bits | Width | Description |
| --- | --- | --- | --- |
| **BDIR** | [7:7] | 1 | PSG BDIR |
| **BC1** | [6:6] | 1 | PSG BC1 |
| **CASS_WR** | [5:5] | 1 | Cassette write data |
| **CASS_MOT** | [4:4] | 1 | Cassette motor (1=on) |
| **KB_LINE** | [3:0] | 4 | Keyboard row select (0–15) |
