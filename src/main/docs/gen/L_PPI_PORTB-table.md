**8255 PPI Port B — VSYNC, Cassette, Printer**

| Field | Bits | Width | Description |
| --- | --- | --- | --- |
| **CASSETTE** | [7:7] | 1 | Cassette data |
| **PRNBUSY** | [6:6] | 1 | 1=busy, 0=ready |
| **EXP** | [5:5] | 1 | Expansion signal |
| **REFRESH** | [4:4] | 1 | 1=50Hz, 0=60Hz |
| **MFG** | [3:1] | 3 | Manufacturer bits |
| **VSYNC** | [0:0] | 1 | 1=active |
