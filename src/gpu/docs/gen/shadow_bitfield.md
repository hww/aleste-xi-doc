**SHADOW Register Format**

| Field | Bits | Width | Description |
| --- | --- | --- | --- |
| <a id="V"></a>**V** | [15] | 1 | Overflow flag |
| <a id="C"></a>**C** | [14] | 1 | Carry flag |
| <a id="N"></a>**N** | [13] | 1 | Negative flag |
| <a id="Z"></a>**Z** | [12] | 1 | Zero flag |
| <a id="RET_ADDR"></a>**RET_ADDR** | [11:0] | 12 | Return address (PC+1) |
