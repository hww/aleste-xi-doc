# LX-GPU

Графический сопроцессор для Z80.

Программируемое микроядро с 32-битными микроинструкциями, тремя каналами
доступа к памяти (SRC, DST, STM), пиксельными форматами 1/4/8/16 bpp и
pass-through режимами. Микрокод загружается пакетами; обмен с CPU — через
MMIO.

## Состав

```
memory.*          — 16-битная память (обёртка над uint8_t*)
pixel_buffer.*    — кэш из 4 записей (SRC / DST / STM / RSV)
pixel_packer.*    — упаковка/распаковка пикселей по fmt
addr_packer.*     — пиксельный индекс → word-адрес + позиция
gpu.*             — микроядро: ALU, управление, операнды, порты
gpu_mmio.*        — регистры для CPU
main.cpp          — тесты
```

## Сборка и запуск

```bash
make
./lx-gpu
```

`make` собирает симулятор, `./lx-gpu` прогоняет набор тестов и печатает
`ALL PASS` или `SOME FAIL`.

## Тесты

`main.cpp` содержит тесты на адресацию, заливку, копирование спрайтов
(4 и 8 bpp), циклы, смену страницы, pass-through режимы, 1 bpp, аффинную
выборку, флаги, условия, умножение, `SHADOW`/`CALL`/`RET`, `JMPR`,
специальные операнды и MMIO.
